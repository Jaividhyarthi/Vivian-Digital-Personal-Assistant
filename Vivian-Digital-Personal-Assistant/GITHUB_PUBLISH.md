# GitHub publication

Target repository: `Jaividhyarthi/Vivian-Digital-Personal-Assistant`.

The connected GitHub tool cannot create new repositories, so publication requires you to create the empty repository at https://github.com/new first. Then use the exact git commands in README.md. **No repository creation or push has been performed by this package.**

Do not include `.env`, credentials, or `vivian.db` in the commit. Check `git status --short` before pushing.
